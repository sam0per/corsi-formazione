# Sessione 5 Blocco 2 Esercizio 3 — Piano di Knowledge Sharing

> ⏱ Tempo stimato: 20 minuti

## Obiettivo

Preparare un piano concreto per trasferire le competenze acquisite ai colleghi Tyvak.

## Istruzioni

### Step 1 — Identificare il pubblico

Compilate la tabella:

| Gruppo target | N° persone stimate | Livello attuale | Cosa devono sapere |
|--------------|--------------------|-----------------|--------------------|
| Team lead / PM | | | |
| Colleghi operativi | | | |
| Nuovi assunti | | | |
| Direzione | | | |

### Step 2 — Definire i contenuti prioritari

Per ogni gruppo target, selezionate i **3 argomenti più importanti** da trasferire:

Scegliete tra:
- Navigazione base di Jira
- Creare e gestire **elementi di lavoro** (work item) correttamente
- Usare i filtri rapidi e la ricerca
- JQL base (le 5 query essenziali)
- Leggere e usare le dashboard
- Aprire work item IT / facility / HR correttamente
- Usare Confluence per documentazione
- Best practice: etichette, componenti, commenti

### Step 3 — Scegliere i formati

Per ogni argomento, decidete il formato migliore:

| Formato | Pro | Ideale per |
|---------|-----|-----------|
| **Sessione live (30-60 min)** | Interattivo, domande in tempo reale | Argomenti complessi, primo approccio |
| **Video tutorial (5-10 min)** | Rivedibile, asincrono | Procedure step-by-step |
| **Pagina Confluence** | Sempre disponibile, aggiornabile | Procedure, FAQ, riferimenti |
| **Affiancamento 1:1** | Personalizzato | Nuovi assunti, casi specifici |
| **Cheat sheet (1 pagina)** | Rapido, stampabile | Sintassi JQL, shortcut |

### Step 4 — Creare il calendario

Definite un calendario realistico per le prossime 4-8 settimane:

| Settimana | Attività | Responsabile | Formato | Target |
|-----------|----------|-------------|---------|--------|
| Sett. 1 | *es. Navigazione base Jira* | *es. IT Manager* | *Sessione live 45 min* | *Team lead* |
| Sett. 2 | | | | |
| Sett. 3 | | | | |
| Sett. 4 | | | | |

**Come misurerete il successo?** Definite almeno 1 metrica per il piano (es. riduzione dei ticket di supporto su Jira, numero di colleghi che usano Confluence attivamente, tempo di onboarding ridotto).

### Step 5 (opzionale) — Creare lo spazio Confluence

> Se il tempo non è sufficiente, completate questo step come attività post-corso.

1. Create (o strutturate) uno spazio Confluence **"Formazione Jira — Tyvak"**
2. Create la struttura delle pagine:
   - Home: panoramica e indice
   - Sotto-pagina: Guide per ruolo
   - Sotto-pagina: FAQ
   - Sotto-pagina: Video e risorse
   - Sotto-pagina: Cheat sheet
3. Collegate i materiali del corso come punto di partenza

## Risultato atteso

- 1 piano di knowledge sharing completo con target, contenuti, formati, calendario e almeno 1 metrica di successo
- Ogni partecipante ha almeno 1 responsabilità specifica nel piano
- (Opzionale) 1 spazio Confluence strutturato per la formazione interna
