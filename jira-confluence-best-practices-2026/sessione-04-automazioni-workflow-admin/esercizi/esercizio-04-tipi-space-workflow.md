# Esercizio 4 — Tipi di spazio e workflow

> ⏱ Tempo stimato: 25 minuti | 👥 In coppia, poi discussione di gruppo

## Obiettivo

Comprendere le differenze tra **spazi** (space) Team-managed e Company-managed e analizzare i workflow esistenti.

## Istruzioni

### Parte A — Confronto tipi di spazio (10 min)

1. Apri uno **spazio** Team-managed (se disponibile) e uno Company-managed
2. Per ciascuno, annota:
   - Dove si trovano le impostazioni dello spazio
   - Se puoi modificare gli status del workflow
   - Se puoi aggiungere nuovi **tipi di lavoro** (work type)
   - Se puoi modificare i campi degli **elementi di lavoro** (work item)
3. Compila la tabella di confronto:

| Caratteristica | Team-managed | Company-managed |
|---------------|-------------|-----------------|
| Chi può configurare il workflow? | | |
| Si possono aggiungere tipi di lavoro? | | |
| I campi sono condivisi con altri spazi? | | |
| Ideale per quale scenario Tyvak? | | |

### Parte B — Analisi workflow (15 min)

1. Vai nelle impostazioni di uno spazio Company-managed
2. Visualizza il workflow associato (**Space settings → Workflows**)
3. Disegna su carta (o su un tool online) il diagramma del workflow:
   - Quali sono gli stati?
   - Quali transizioni sono possibili?
   - Ci sono **regole** (rules) associate alle transizioni?
4. Confronta con il workflow di uno spazio Team-managed

**Sfida extra per l'IT Manager:**
- Identifica quale workflow sarebbe ideale per gli elementi di lavoro IT dell'helpdesk
- Bozza uno schema con gli stati: `Nuovo → In analisi → In lavorazione → In attesa di feedback → Risolto → Chiuso`

## Risultato atteso

- Tabella di confronto compilata
- Diagramma di almeno un workflow esistente
- (IT Manager) Bozza del workflow ideale per helpdesk IT

## Domande di riflessione

- Per il vostro team, quale **tipo di spazio** (space type) sarebbe più appropriato?
- Quali stati mancano nei workflow attuali per gestire meglio il vostro lavoro?
