# Design: Complete Slides 6, 8, 9, 10 — Sessione 01

> Date: 2026-02-23

## Context

Slides 6, 8, 9, 10 in `sessione-01-fondamenti-jira.md` have titles only and no content.
They are part of Blocco 1 (Architettura e Navigazione), which has 20 minutes allocated.
Session 4 covers workflows and administration in depth, so these slides serve as concise introductions.

## Decisions

- **Depth**: Concise overview — summary table per slide with brief context
- **Format**: Table-centric, consistent with existing slide 7 (Tipi di lavoro)
- **Pattern**: Each slide includes intro line, table, and team-managed/company-managed note where relevant

## Slide Content

### Slide 6: Tipi di schema

Overview of the 5 scheme types (Work Type, Workflow, Screen, Permission, Notification) with brief descriptions. Blockquote noting team-managed spaces manage these directly.

### Slide 8: Tipi di workflow

Two-row table (Predefinito vs Personalizzato) with description and typical use. Bullets for team-managed/company-managed behavior. Forward reference to Session 4.

### Slide 9: Tipi di schermata (Screen)

Three-row table for Create/Edit/View screen contexts with when they appear and example fields. Bullets for team-managed/company-managed differences.

### Slide 10: Tipi di permesso (Permission)

Bullets introducing global vs space-level permissions. Five-row table of key space permissions (Browse, Create, Edit, Assign, Transition). Forward reference to Session 4.
